# Function copying the description and the input path from files to the PARAM_GLOBAL

Write the description and the input path from text files to the
PARAM_GLOBAL.

## Usage

``` r
copy_param(path, path_out)
```

## Arguments

- path:

  Path of the parameter folder.

- path_out:

  Directory to store the output folder.
