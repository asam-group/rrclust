# Function to generate descriptive statistics

Generate descriptive statistics as the mean, the median, among others.

## Usage

``` r
descr_stat_fun(descrstat_dpath, lvalues)
```

## Arguments

- descrstat_dpath:

  Directory to store the tex files containing the descriptive
  statistics.

- lvalues:

  List of variables and values to be analysed. The list must have
  variable names.

## Value

Latex tables.
