# Function to read the data

Function to read the data.

## Usage

``` r
mod_inp_kamila(path, list = NULL, method_name = "kamila")
```

## Arguments

- path:

  Path of the set of parameters set to a particular output.

- list:

  Path where the outputs are saved.

- method_name:

  Name of the clustering method.

## Value

`tl_inp` Tidylist of inputs.
