# Read of the pension register

Read the pension register and save it into an tidy data frame.

## Usage

``` r
mod_input_ind_yearly_rr(PARAM_INPUTS, list = NULL)
```

## Arguments

- PARAM_INPUTS:

  a data frame containing the data paths.

- list:

  List of input data frames.

## Value

a `tidylist` containing the following tidy data frames:

- `IND_YEARLY_RR` : contains all the beneficiaries of the OASI
