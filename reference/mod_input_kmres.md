# Read of the kamila results of the training set

Read the kamila results of the training set and save the optimal number
of clusters kstar.

## Usage

``` r
mod_input_kmres(PARAM_INPUTS, list = NULL)
```

## Arguments

- PARAM_INPUTS:

  a data frame containing the data paths.

- list:

  List of input data frames.

## Value

a `tidylist` containing the following tidy data frames:

- `KM_RES` : contains the kamila results of the training set.
