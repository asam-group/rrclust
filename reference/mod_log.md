# Write the version of the packages

Write the version of the rrclust and dplyr packages and the time of the
output production.

## Usage

``` r
mod_log(list = NULL)
```

## Arguments

- list:

  List of input data frames.

## Value

`LOG` Tibble with information about time and packages version.
