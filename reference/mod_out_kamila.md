# Write the directory of the output container

SWrite the directory of the output container.

## Usage

``` r
mod_out_kamila(path, path_out, tl_inp_kamila, tl_out_kamila)
```

## Arguments

- path:

  Vector containing container path.

- path_out:

  Vector containing output path.

- tl_inp_kamila:

  List containing input data Kamila.

- tl_out_kamila:

  List containing output data Kamila.

## Value

`path_out_identifier`: Path to output container.
