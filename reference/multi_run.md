# Write a message and execute the function applied on one or more containers

Write a message and execute the function applied on one or more
containers.

## Usage

``` r
multi_run(path, fun, ...)
```

## Arguments

- path:

  Path of the parameters container.

- fun:

  Function to run for each of the given paths.

- ...:

  Any other arguments.
