# Resolve the path_out

Writes the path_out and the unique identifier_number of the output.

## Usage

``` r
path_out_resolve(path_out, identifier_number)
```

## Arguments

- path_out:

  Directory to store the output folder.

- identifier_number:

  Unique identifier number to name the output folder.

## Value

Path_out directory to store the output.
