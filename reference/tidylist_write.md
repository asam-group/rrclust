# Write a list of CSV files

Write a list of CSV files.

## Usage

``` r
tidylist_write(x, path = ".", fst = FALSE, verbose = TRUE)
```

## Arguments

- x:

  Object to write.

- path:

  Path to file.

- fst:

  If TRUE, write fst, otherwise csv.

- verbose:

  Print a message if TRUE.
