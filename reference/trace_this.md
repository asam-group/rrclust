# Trace the inputs ([`mod_init`](https://asam-group.github.io/rrclust/reference/mod_init.md)) and the outputs

Trace the inputs
([`mod_init`](https://asam-group.github.io/rrclust/reference/mod_init.md))
and the outputs
([`mod_return`](https://asam-group.github.io/rrclust/reference/mod_return.md)).

## Usage

``` r
trace_this(x, at = "", mod = "")
```

## Arguments

- x:

  Tidylist.

- at:

  öevel of the module ("input" or "output").

- mod:

  Name of the module function.
